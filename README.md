# Mercado de Intercambios 

Aplicación serverless (Vite + Vanilla JS + Firebase) para crear salas privadas e intercambiar productos en tiempo real. 

**Despliegue:** El proyecto está planteado para alojarse a través de **GitHub Pages**.

## Desarrollo local

1. Asegúrate de tener [Node.js](https://nodejs.org/) instalado.
2. Clona el repositorio y abre una terminal en la carpeta del proyecto.
3. Instala las dependencias:
   ```bash
   npm install
   ```
4. Levanta el servidor local:
   ```bash
   npm run dev
   ```
